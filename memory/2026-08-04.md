## The audit

Same method as the last two passes
(`ARCHITECTURE.md#auditing-which-repos-have-live-pages`): enumerate every repo on
the account, then ask the server what a visitor would actually get —

```bash
curl -s -o /dev/null -w '%{http_code}' -L "https://digster.github.io/<repo>/"
```

The GitHub REST API isn't reachable directly from this session (it's bound to the
configured repo), so the repo list came from the GitHub MCP `search_repositories`
tool with `user:digster` — **65 repos** (64 public + the private `obsidian`).

**Result: 15 × `200`, 50 × `404`.** The 15 are `digster.github.io` itself, the 13
already-listed projects, and one new one. No other status codes appeared — no
redirect-loop or server-error cases to investigate.

## What changed (`data/sites.json` only — 13 → 14 entries)

**Added:** `syllabus` (repo created 2026-08-03) as slot 14 —

```json
{
  "name": "syllabus",
  "title": "Syllabus Library 🧭",
  "description": "Self-directed study plans — each topic gets a sequenced syllabus of modules, exercises and checkpoints, backed by a categorized reading list.",
  "url": "https://digster.github.io/syllabus/",
  "repo": "https://github.com/digster/syllabus",
  "tags": ["learning", "reference"]
}
```

- **What it is:** a catalog of full courses of study — per topic, a sequenced
  syllabus (modules, exercises, checkpoints, capstone, mastery check) plus a
  categorized reading list every module links into. Currently one topic live
  (Information Theory, 13 modules / 50 resources), grouped under "Mathematics &
  statistics" with room for more groups.
- **Description written to not rot:** deliberately describes the *shape* of an
  entry rather than quoting today's topic count — a one-topic library will grow,
  and hard-coding "1 topic" would go stale within the week. (Contrast the course
  entries, whose lesson counts are fixed and so are quoted.)
- **Emoji 🧭** — the site's own line is "Read this, in this order, for this
  reason"; a compass is the guided-path glyph and wasn't already in use. Checked
  programmatically for duplicates against the other 13.
- **Tags reuse the existing vocabulary** (`learning`, `reference`) — no new chip
  invented. Deliberately *not* `tutorial`: that chip means the hands-on
  build-along courses (SDL3 Recipes, Koi Engine, Renderbook, 3D Physics), and a
  reading-and-study plan isn't one. Nearest neighbour is Topic References, which
  carries the same pair.

**Removed:** nothing. All 13 existing `url` values still answer `200` — no repo
was renamed out from under an entry this time.

**Not added:** the other 50 repos all `404` (source-only or Pages never enabled).
The same promising-sounding names as last time are still dark: `sdl3-2d`,
`3d-book`, `img2pxl`, `paint-sim`, `canvas`, `interactive-studio`,
