## Notes
- No code, CSS or markup touched, and no doc convention changed, so `README.md`
  and `ARCHITECTURE.md` needed no edits — numbering, the index count and the tag
  chips all derive from the data. `PROMPT.md` got this session's prompt.
- **Test-harness gotcha (cost two runs, worth remembering):** `#active-filter-tag`
  — the "Filtering by #x" banner — also carries `class="tag"`, and it sits
  *above* `#grid` in the DOM. So `page.locator('.tag:text-is("#reading")').first()`
  resolves to the banner once a filter is active, and clicking it silently does
  nothing (the chips' handlers are on the cards). Scope tag clicks to
  `#grid .tag[data-tag="…"]` and clear via the `#clear-filter` button.
  Likewise, count visible cards as `#grid .entry:not([hidden])` — `render()`
  filters with the `hidden` attribute, and assert the empty state on
  `#empty:not([hidden])` rather than sniffing `#grid` text (a substring match
  against the whole grid passes for the wrong reason).
- `curl` to `127.0.0.1` needs `--noproxy '*'` in this sandbox; without it the
  session's `HTTPS_PROXY` swallows the request and returns `000`, which looks
  like "the local server never started" when it is in fact up.
- Playwright is installed globally here, not in this repo. ESM ignores
  `NODE_PATH` and the package is CommonJS, so the import that works is
  `import pw from '/opt/node22/lib/node_modules/playwright/index.js'` then
  destructure — not a named import.
- Keep re-running the probe: it catches renames and removals, not just additions.
