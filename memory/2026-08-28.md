**Added:** `books` (repo created 2026-08-25) as slot 18 —

```json
{
  "name": "books",
  "title": "The Understudy 🎭",
  "description": "Readthroughs that transmit what a book actually contains — its arguments, machinery, evidence and cases — in enough depth that reading the pages gives you what reading the book would have.",
  "url": "https://digster.github.io/books/",
  "repo": "https://github.com/digster/books",
  "tags": ["reading", "learning"]
}
```

- **What it is:** long-form *readthroughs* — pages that transmit a book's
  arguments, machinery, evidence and cases at enough depth that reading them
  gives you what reading the book would have. Its own framing: "a summary tells
  you what a book is about, these pages tell you what is *in* it — the
  difference between a menu and a meal." Nothing is asked of the reader (no
  exercises, no drills, no tracking); the bar it sets itself is that you could
  discuss the book for an hour with someone who read it cover to cover and never
  be caught out. Hand-authored static HTML, no build step, no JavaScript, no
  network.
- **Title from the site, not the slug** — repo `books`, site "The Understudy".
  Same split as `research-topics-explorer` → "The Vault 🗝️" and `book-reviews` →
  "The Deep Read 📖". The slug still lives in `name`, so search finds both.
- **Not a duplicate of The Deep Read** — and the repo's own README says so
  loudly, because `digster/book-reviews` briefly occupied the same folder. *A
  review is a verdict; a readthrough is a transmission.* The descriptions are
  written to hold that line: The Deep Read "tests what a book predicts and says
  where it doesn't hold"; The Understudy "transmits what it contains". Keep both
  descriptions method-first or the two entries will start to read alike.
- **Description written to not rot:** describes the method every page follows and
  quotes no counts — the shelf held one book (Clark, *Surfing Uncertainty*, 10
  parts / 34,569 words) the day it was added and will grow. (Contrast the course
  entries, whose lesson counts are fixed and so are quoted.)
- **Emoji 🎭** — the name is a theatre term: an understudy stands in and performs
  the part. Deliberately *not* a third book glyph — 📖 (The Deep Read) and 📚
  (Topic References) already carry that shape, and a third would be the opposite
  of the tell-them-apart logic that gives the four "build a 3D thing" entries
  🐟 / 🎱 / 🔺 / ⚙️. Checked programmatically against the other 18.
- **Tags reuse the existing vocabulary** (`reading`, `learning`). The pair with
  The Deep Read (`reading`, `research`) is the point: both are prose about books,
  but one exists to teach you the contents and the other to argue about them.

- **What it is:** an animated world map covering 3500 BCE to today. Territories

  event marks, 0.25×–8× playback, pan/zoom, click anything for details, fully
  keyboard-navigable. Vite + TypeScript, dataset authored in TS and baked to
  static JSON — no backend.
- **Sourcing note:** like MindFlow, the live page is a JS app whose static text
  is just the title and a loading string, so the description came from the repo
  (shallow read-only clone via the proxy — `add_repo` reported public repos need
  no attachment) plus the page's `<meta name="description">`.

- **Emoji 🗺️** — a world map, which is literally what the site is; unused, and
